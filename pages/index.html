Gaze Control Music UI

  • Gaze interface

    The gaze-controlled sequencer. Uses the webcam (WebGazer.js) and, once enabled, Web Serial to talk to the Arduino.

  • WebGazer test

    Test page for webcam eye tracking, calibration and accuracy.

Camera and Web Serial access need Chrome or Edge. The Serial sender page is not available here: it needs the local Node server. Run npm start and open http://localhost:3000 to use it.
